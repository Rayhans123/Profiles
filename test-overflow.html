📋 Manual Verification Checklist

Test these manually in your browser:

  • ✓ Open index.html in Chrome, Firefox, and Edge
  • ✓ Resize window from 320px to 1920px - no horizontal scroll
  • ✓ Test mobile menu: open, close, click links, press Escape
  • ✓ Tab through all interactive elements - visible focus
  • ✓ Test form: all inputs should be 16px or larger
  • ✓ All images should maintain aspect ratio
  • ✓ Grid should be: 1 col (mobile), 2 cols (768px), 3 cols (1024px)

🔧 Browser DevTools Tests

  1. Chrome DevTools: F12 → Toggle device toolbar (Ctrl+Shift+M)
  2. Test viewports: 320px, 375px, 768px, 1024px, 1440px
  3. Run Lighthouse: F12 → Lighthouse tab → Mobile → Generate report
  4. Check console: Should have no errors
  5. Overflow test: Paste this in console:
document.querySelectorAll('*').forEach(el => {
  const r = el.getBoundingClientRect();
  if (r.right > document.documentElement.clientWidth + 1) {
    console.log('OVERFLOW:', el, 'right:', r.right);
  }
});
